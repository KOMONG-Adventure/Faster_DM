# Download Faster DM

[Download Windows installers from official GitHub Releases](https://github.com/KOMONG-Adventure/Faster_DM/releases).

Faster DM is a Mongolian-language desktop download manager for parallel HTTP
downloads, resumable transfers, queues, speed limits, file organization, and
download history. It also includes third-party tools for YouTube downloads.

## Code signing policy

We are applying to the [SignPath Foundation](https://signpath.org/) for code signing.
**SignPath approval and signed builds are not yet available.** Existing installers
may be blocked by Windows Smart App Control. We do not claim that current releases
are signed or endorsed by SignPath.

Read our [Code signing policy](CODE_SIGNING_POLICY.md), [privacy policy](PRIVACY.md),
[MIT license](LICENSE), and [third-party notices](THIRD_PARTY.md).

Release checksum files help detect corrupted downloads, but are not a substitute
for a trusted Authenticode signature.
