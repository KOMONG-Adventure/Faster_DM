# Faster DM — Chrome / Edge өргөтгөл

1. Faster DM **v0.6.0 буюу түүнээс шинэ installer** суулгана. «Chrome/Edge өргөтгөлийн холболт бүртгэх» сонголтыг асаалттай үлдээнэ.
2. Chrome-д `chrome://extensions`, Edge-д `edge://extensions` нээгээд **Developer mode** асаана.
3. **Load unpacked** → `%LOCALAPPDATA%\Programs\FasterDM\extension` хавтсыг сонгоно.
   Release-ийн extension ZIP-ийг задалсан `extension` хавтсыг бас ашиглаж болно.
4. Өргөтгөлийн ID: `ppifjgnggblnhpndbldhbcakkbcipkof`. Хоёр браузерт ижил ID байна.

## Ашиглах

- Файлын холбоос дээр баруун товч → **Faster DM рүү дамжуулах**.
- Өргөтгөлийн товчоор одоогийн хуудас/YouTube холбоос эсвэл өөр холбоос оруулж дамжуулна.
- **Браузерын сүүлийн таталтууд**-ыг анх дарахад нэмэлт downloads зөвшөөрөл асууна.
  Файлаа сонгоод апп руу дамжуулна. Өмнөх браузерын таталтыг автоматаар цуцлахгүй.
- Апп хаалттай бол нээнэ. Холбоос нь хоосон татах талбарт орно. **Зай шалгах → Татаж эхлэх**.
  Талбарт өөр холбоос байвал түүнийг дарж бичихгүй; талбарыг хоослоход дараагийн холбоос орно.

## Хязгаар

Өргөтгөл Chrome Web Store / Edge Add-ons-д хараахан нийтлэгдээгүй. Браузерын өөрийн
нэвтрэх cookie, Authorization, POST хүсэлт болон blob: URL-ийг дамжуулахгүй.
Нэвтрэх шаардлагатай эсвэл хугацаа нь дууссан холбоос аппд татагдахгүй байж болно.
DRM тойрох, бүх браузерын таталтыг автоматаар барих боломж ороогүй.

Smart App Control unsigned native host-ийг блоклож болно. SignPath-ийн зөвшөөрөл
болон гарын үсэгтэй release хараахан гараагүй; хамгаалалтын тохиргоог өөрчлөхгүй.

## Нууцлал

Зөвхөн хэрэглэгчийн сонгосон HTTP/HTTPS холбоосыг локал native host-д илгээнэ.
Хүлээгдэж буй холбоос `%APPDATA%\FasterDM\browser-inbox` дотор апп хүлээн авах хүртэл
хадгалагдана. Өргөтгөл аналитик, сервер рүү холбоос илгээх код агуулаагүй.
`activeTab` нь зөвхөн хэрэглэгч өргөтгөлийг ажиллуулахад тухайн табын URL-д хүрнэ.
`downloads` нь хэрэглэгч зөвшөөрсөн үед сүүлийн 10 таталтын жагсаалтад ашиглагдана.
